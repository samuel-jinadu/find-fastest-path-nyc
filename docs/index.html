Taxi vs. Citi Bike — fastest mode between two zones

The question is the payload. The engineering is heterogeneous ingestion, unit conformance, and idempotent serving.

Based on Chapter 13
Data Pipelines with Apache Airflow, 2nd Ed.
🚲 Citi Bike API Backfillable
REST + HTTP Basic · JSON list of rides · stations as lat/lon · full year retained
🚕 Yellow Cab fileserver Not backfillable
Static file share, no auth · one CSV per 15-min window · taxi zone IDs · files deleted after 59 min

The Problem — four at once

1
Asymmetric retention

Taxi files are deleted 59 minutes after they appear. A two-hour scheduler gap is permanent loss for taxi; Citi Bike can be refetched.

2
Unit mismatch

Citi Bike reports station lat/lon. Taxi reports zone IDs. Without a reference join there is no shared key to compare on.

3
Two protocols

One source is an authenticated REST API; the other is a directory listing plus per-file CSV fetches. One operator cannot serve both.

4
Idempotent reruns

Re-running the 14:15 interval must not duplicate rows, and must not depend on how many times it has already run.

The Solution — raw → processed → serving

🌐
Sources · outside the DE boundary

A mock Flask API and a mock nginx file share stand in for the real upstreams.

📦
Raw · MinIO · source of record

Byte-for-byte source output. Because taxi deletes after 59 min, this is the only copy of that window — re-processing never re-hits the API.

🔧
Processed · MinIO · conformed Parquet

Both sources reduced to the same five columns: tripduration, starttime, start_location_id, stoptime, end_location_id.

🗄️
Serving · Postgres · result_db

taxi_rides and citi_bike_rides, every row tagged with airflow_execution_date. The DE work ends here.

How It's Built — four mechanisms

Interval-matched scheduling

CronDataIntervalTimetable("*/15 * * * *", "UTC"). data_interval_start becomes the object key, the taxi mtime filter, and the idempotency key.

PandasOperator

input → [transform] → output. The only contract is "DataFrame in, DataFrame out", so both protocols share one operator — the difference lives in the callables.

Conformance join

geopandas.sjoin maps Citi Bike station points onto NYC taxi zone polygons, giving both sources the same location unit.

Atomic replacement

with engine.begin(): DELETE the interval's slice, then INSERT the new one in a single transaction — a rerun replaces, never duplicates.
